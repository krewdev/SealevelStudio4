## 🔍 Quick Reference

### Key Concepts
- **Sharding**: Network split into multiple shards
- **Intra-Shard**: Transactions within same shard (faster)
- **Cross-Shard**: Transactions across shards (slower)
- **Adaptive Sharding**: Dynamic shard reorganization
